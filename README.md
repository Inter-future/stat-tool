# 描述性统计工具箱

单一 HTML 文件实现的前端统计工具，无需安装、无需联网，双击即可运行。

- **课程**：数据挖掘
- **技术栈**：原生 HTML + CSS + JavaScript，Canvas 手工绘图，零第三方依赖

## 功能概览

### 一、集中趋势度量
算术均值、中位数、众数、P25/P50/P75 分位数、10% 截尾均值、几何均值、极值。

### 二、离散程度度量
极差、四分位距 IQR、样本方差与样本标准差（n−1）、总体标准差（n）、平均绝对偏差 MAD、变异系数 CV、标准误 SE。

### 三、分布形态度量
偏度 G1（附右偏/左偏判断）、峰度 G2（超额，正态为 0）、1.5×IQR 异常值栅栏与异常值检测、Jarque-Bera 检验、Kolmogorov-Smirnov 正态性检验。

### 四、常用统计工具（图表）
直方图＋正态参考曲线、箱线图（含栅栏与异常值标注）、Q-Q 图、经验累积分布 ECDF、分组箱线图。

### 五、交互与辅助功能
- 数据输入：手动粘贴、内置示例、按分布随机生成、CSV 导入（支持 GBK/UTF-8 自动识别）
- 离群点注入滑杆：实时观察均值、标准差被拉动而中位数几乎不动，直观演示稳健性
- 分组对比：识别带组名的数据，输出分组箱线图与组间指标对照表
- 一键导出：将四张图拼合为单张 PNG 便于插入报告
- 自动解读：根据当前数据生成中文统计结论
- 软件对照表：Excel / SPSS / R / Python 各指标的实现方式

## 使用说明

1. 双击 `index.html`，用 Edge 或 Chrome 打开
2. 在输入区粘贴一列数字（逗号、空格、换行分隔均可），点击「解析并计算」
3. 拖动「离群点注入」滑杆，观察各项指标与图形的实时变化

## CSV 格式

单列数据：

```csv
成绩
78
85
92
```

带分组的双列数据（自动进入分组对比模式）：

```csv
班级,成绩
A班,78
A班,85
B班,91
B班,88
```

## 说明

所有计算均在浏览器本地完成，数据不会上传至任何服务器。
偏度与峰度采用样本调整口径（G1、G2），与 Excel 的 `SKEW`/`KURT`、SPSS 描述统计一致。
